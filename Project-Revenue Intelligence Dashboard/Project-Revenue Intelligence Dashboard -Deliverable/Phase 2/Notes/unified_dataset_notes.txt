Unified Dataset Overview
The Unified Dataset combines three NovaTech datasets:

CRM Deals
Marketing Campaigns
Support Tickets
All datasets are joined using account_id as the common key.

Join Logic
Join 1 — CRM + Marketing
Left Join
Left Table: CRM
Right Table: Marketing
Join Key: CRM.account_id = Marketing.account_id
Reason: CRM is the anchor dataset; not all accounts have marketing campaigns.

Join 2 — Support + (CRM + Marketing)
Left Join
Left Table: Support
Right Table: Join 1 result
Join Key: Support.account_id = CRM.account_id
Reason: Support tickets enrich CRM accounts; all CRM accounts must remain.

Calculated Fields
Three calculated fields were added to enrich the unified dataset:

1. Deal Duration (days)
Code
dateDiff({deal_closed_date}, {deal_created_date}, 'DD')
Measures sales cycle length.

2. Marketing ROI
Code
({deal_value} - {campaign_spend}) / {campaign_spend}
Evaluates campaign effectiveness.

3. Support Efficiency Score
Code
100 * (1 - ({Resolution Time (days)} / 30))
Normalizes resolution time (in days) into a 0–100 efficiency score.
